# Secure Printer Scan-to-Email Integration

A sanitized case study covering an enterprise scan-to-email workflow:

**Printers → Postfix SMTP Relay → Exchange Online → Recipient**

Key areas: printer SMTP configuration, Postfix relay, SMTP authentication, TLS, Exchange Online mail flow, Message Trace, logging and layer-by-layer troubleshooting.

Environment-specific tenant names, IP addresses and credentials are intentionally omitted.
