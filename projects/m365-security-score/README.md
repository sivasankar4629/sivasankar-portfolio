# M365 Security & Secure Score Improvement

## Overview

A sanitized case study covering Microsoft 365 security hardening and operational improvements that increased Microsoft Secure Score from **76% to 92%**.

## Scope

- Conditional Access and MFA enforcement
- Entra ID identity security
- Risky sign-in monitoring
- Compromised-account investigation and remediation
- Defender for Office 365 investigations
- Safe Links and Safe Attachments
- Threat Explorer and quarantine workflows
- Microsoft Purview and audit logging
- Review and removal of unnecessary access
- Security reporting and remediation

## Approach

1. Assess security recommendations and current controls.
2. Prioritize improvements based on security impact and operational requirements.
3. Implement and validate applicable controls.
4. Monitor security signals and continue remediation.

## Result

**Secure Score: 76% → 92%**

The project improved the tenant's security posture while establishing more consistent identity, email-security, monitoring and remediation practices.

> Customer names, tenant identifiers, domains and user information are intentionally excluded.
